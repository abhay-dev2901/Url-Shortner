# LinkShort

A simple Android URL shortener built with Kotlin and Jetpack Compose. It sends URLs to the free is.gd shortening service; no API key or account is required.

## Open in Android Studio

1. Open Android Studio and choose **Open**.
2. Select this project folder.
3. Allow Gradle to sync and install Android SDK 35 if prompted.
4. Start an emulator or connect an Android device, then click **Run**.

The device needs an internet connection to shorten links. Enter a complete `https://` or `http://` URL, then use **Copy**, **Open**, or **Share** on the result.
